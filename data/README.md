# Data

`station.csv`: one year (2025) of **synthetic** daily values for an imaginary station with a Lisbon-like climate.
Made up for this exercise; not measurements.

| Column | Meaning | Unit |
|---|---|---|
| `date` | day | YYYY-MM-DD |
| `tmin_c` | minimum temperature | °C |
| `tmax_c` | maximum temperature | °C |
| `rain_mm` | rainfall | mm |
